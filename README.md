# Smart Bharat - AI Companion 🇮🇳

Public schemes aur civic issue tracking ke liye ek smart AI platform.

## Key Features
* **AI Assistance:** Government schemes (Ayushman Bharat, Ration Card, etc.) ki jankari.
* **Civic Issue Tracker:** Local civic complaints track aur report karne ke liye.
* **Document Assistant:** Utility forms aur policies ki verification.
* **Mobile Ready:** Laptop aur phone dono par fully responsive UI.

## Tech Stack
* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **AI:** Google Gemini API
